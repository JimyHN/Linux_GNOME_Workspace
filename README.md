# Linux_GNOME_Workspace

Configuración personal del escritorio GNOME: ajustes de `dconf`, extensiones,
temas y scripts para reconstruir el entorno de trabajo en una máquina nueva.

## Estado

Repositorio recién iniciado. Aún no hay configuración volcada.

## Uso previsto

```bash
git clone https://github.com/JimyHN/Linux_GNOME_Workspace.git
cd Linux_GNOME_Workspace
./scripts/install.sh
```

> Los scripts modifican la sesión de GNOME. Revisa qué hace cada uno antes de
> ejecutarlo y cierra sesión para que todos los cambios se apliquen.
